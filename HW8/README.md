# HW8 — Multi-class Classification

**Goal:** Predict students' grade class (5 classes) from study habits and background, using a range of classifiers.

- SVM; multinomial vs. one-vs-rest logistic regression (with log loss); KNN with grid search; decision trees.
- Boosting: **XGBoost**, **LightGBM** and **AdaBoost**.
- Evaluated with weighted F1. The best model reaches **F1 ≈ 0.80**.
