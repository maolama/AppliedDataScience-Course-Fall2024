# HW6 — Regression Methods

**Goal:** Compare classical regression methods on a house-price prediction task (US housing dataset).

- Preprocessing (normalization vs. standardization) and correlation analysis.
- Linear regression, kernel regression (polynomial and RBF), logistic regression, and **Ridge** and **Lasso** with grid-searched regularization strength.
- The best models reach **R² ≈ 0.92** (linear and Ridge).
