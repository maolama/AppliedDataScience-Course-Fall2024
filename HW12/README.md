# HW12 — Autoencoders and Generative AI

**Goal:** Learn compact image representations, and try out generative-AI APIs.

- **Autoencoders on Fashion-MNIST:** dense vs. **convolutional** autoencoders, and a **denoising** autoencoder trained to reconstruct clean images from Gaussian-noised inputs.
- **Generative AI APIs:** OpenAI examples (text, image and speech; these need paid credits), and text generation with **Llama-3.3-70B** through the Groq API.

Notebook: [`HW12_Autoencoders_GenAI.ipynb`](HW12_Autoencoders_GenAI.ipynb) · Set your own key where `YOUR_GROQ_API_KEY` appears.
