# HW11 — Convolutional Neural Networks and Transfer Learning

**Goal:** Design and tune CNNs systematically, and use pretrained models.

- **Fashion-MNIST CNN:** k-fold cross-validated tuning of kernel size, convolution stride, pooling size and pooling stride (best ≈ 85% CV accuracy).
- Data augmentation.
- **Transfer learning** with **VGG19** and **ResNet**, plus an analysis of how receptive-field size affects performance.
