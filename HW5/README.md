# HW5 — Accuracy Measures

**Goal:** Choose and interpret the right evaluation metrics for each type of task.

- **Regression – real-estate price prediction:** MAE, MSE, MAPE and R² (R² ≈ 0.68).
- **Binary classification – breast cancer:** accuracy, precision, recall and F1 (accuracy 0.96, F1 0.94).
- **Multi-class classification – student performance:** per-class and averaged metrics from classification reports.

Notebook: [`HW5_Accuracy_Measures.ipynb`](HW5_Accuracy_Measures.ipynb) · Data: `real_estate.csv`, `breast-cancer.csv`, `student_performance.csv`
