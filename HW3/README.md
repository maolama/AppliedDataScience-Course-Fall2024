# HW3 — Data Visualization and Web Scraping

**Goal:** Communicate data visually and collect new data from the web.

- **Visualization (Refah dataset):** pie, box, line (with uncertainty bands), bar, scatter and bubble charts, plus interactive **Bokeh** plots.
- **Web scraping:** a scraper for the **Bama.ir** car-listing API that collects about 430 Samand car ads (title, mileage, color, year, transmission, price, description) into a spreadsheet.

Notebooks: [`HW3_Data_Visualization.ipynb`](HW3_Data_Visualization.ipynb) · [`HW3_Web_Scraper.ipynb`](HW3_Web_Scraper.ipynb) · Data: [`scraped_samand_ads.xlsx`](scraped_samand_ads.xlsx)

*Raw-record previews of the Refah data have been cleared from the outputs for privacy.*
