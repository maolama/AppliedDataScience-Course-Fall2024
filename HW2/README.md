# HW2 — Exploratory Data Analysis and Data Cleaning

**Goal:** Clean and explore a large, messy real-world dataset.

- Dataset: a 2% sample of the Iranian **Refah** (welfare) household dataset, with demographics, location, assets and more. The data itself is not included.
- Assess data quality (unique values, null ratios), drop irrelevant columns, fill missing values with justified strategies, and categorize features.
- Correlation analysis, normalization vs. standardization, and distributions (e.g. registered vehicles per person), with Persian-text plotting support.

Notebook: [`HW2_EDA_Data_Cleaning.ipynb`](HW2_EDA_Data_Cleaning.ipynb)

*Raw-record previews have been cleared from the outputs for privacy.*
